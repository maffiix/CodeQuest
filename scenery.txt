Задача 2:
В сейчас находитесь на подьезде к городу и надо выбрать наилучший съезд с шоссе а так же знать время через которое мы будем дома (для консьержки) и в департаменте разведки(для важных людей)
Оказалось что случились временные перебои мобильной связи так что есть только бумажная карта, но пока вы были в аэропорту вы успели узнать о перекрытых дорогах

На вход подаются
Сначала список сьездов с шоссе в виде BH-01-1[BH-01-ОДНА ЦИФРА] J-1321[ЛАТИНСКАЯ БУКВА "J"-Число от 1 до 9999]
Заканчивается ввод сьездов вводом слова END
Дальше перечисляются перекрёстки и куда можно доехать от каждого перекрёстка. С каждого перекрётска может быть 4 соединения в которых может находится только один сьезд
в формате:
J-1 J-2:5 J-3:5 J-5:3 BH-01-1:1
[описываемый перёкресток, куда можно попасть:время в минутах]
ввод перекрёстков завершается вводом END
Дальше ввод перекрытых дорог
Всё просто вводим пару [Сьезд или перекрёсток-Сьезд или перекрёсток]
J-112:BH-01-1
Ввод заканчивается END_ALL

Надо посчитать оптимальный путь, показать название Сьезда с которого будет путь проходящий через J-1212 и Заканчивающийся J-24, и время пути в минутах. Считать что время пребывания в доме равно 30 минут, время сьезда с дороги до перекрёстка 1 минута.
Все возможные выводы INCORRECT INPUT с условиями их вызова:

INCORRECT INPUT: invalid exit format '...'
Вызов: формат съезда не соответствует BH-XX-Y (где X - цифра, Y - одна цифра) или J-число от 1 до 9999

INCORRECT INPUT: expected END after exits
Вызов: после списка съездов нет слова END

INCORRECT INPUT: invalid node format '...'
Вызов: название перекрёстка не начинается с J- или после J- не число

INCORRECT INPUT: node ... has X connections, expected 4
Вызов: у перекрёстка не ровно 4 соединения

INCORRECT INPUT: invalid edge format '...' at ...
Вызов: формат ребра не содержит двоеточие

INCORRECT INPUT: invalid time '...' at ...->...
Вызов: время после двоеточия не является целым числом

INCORRECT INPUT: invalid target node format '...' at ...
Вызов: узел назначения не является J-число и не является BH-XX-Y

INCORRECT INPUT: expected END after intersections
Вызов: после списка перекрёстков нет слова END

INCORRECT INPUT: exit ... not connected to any intersection
Вызов: съезд указан в списке съездов, но ни один перекрёсток не имеет соединения с этим съездом

INCORRECT INPUT: invalid blocked road format '...'
Вызов: формат перекрытой дороги не содержит двоеточие

INCORRECT INPUT: blocked road node '...' not found
Вызов: в перекрытой дороге указан узел, которого нет в графе

INCORRECT INPUT: J-1212 not found in graph
Вызов: в графе нет перекрёстка J-1212

INCORRECT INPUT: J-24 not found in graph
Вызов: в графе нет перекрёстка J-24

INCORRECT INPUT: no valid path found
Вызов: нет пути от какого-либо съезда до J-24 через J-1212

Задача: 3
О НЕТ БЮРОКРАТЕЯ

Надо создать json файл на новые модели техники
ПО БЮРОКРАТИЧЕСКИМ СТАНДАРТАМ

Должны быть тэги ABBR (аббревиатура. например MSV-AA-R90), Name (название техники. например aerophobous), CrDat (дата создания), Type (тип техники), если их не было указано ставить заглушку N/A

ВВОД:

ABBR: ******
Name: ******
CrDat: YYYY/MM/DD (Дата создания по ISO 8601)
Type: ******
[хар-ка 1]: [данные хар-ки 1]
[хар-ка 2]: [данные хар-ки 2]
....
[хар-ка n]: [данные хар-ки n]

ввод заканчивается ^Z (ctrl-z)
ПУСТЫЕ СТРОКИ ПРОПУСКАТЬ

ВЫВОД:

> ******.json (****** это название техники)

Обязательно должны присутствовать ключи ABBR Name CrDat Type. Если они не были определены в значение подставить N/A.

В случае неверного формата даты подставить N/A и вывести в консоль WARING: INCORRECT DATE INPUT

В случае если Name не указан (остался N/A), имя файла должно быть unnamed.json

Пример 1:

Ввод:
ABBR: MSV-AA-R90
Name: aerophobous
CrDat: 2042/11/05
Type: Зенитный ракетный комплекс
Range: 90 км
Ammo: 12 ракет
^Z

Вывод:
> aerophobous.json

Содержимое aerophobous.json:
{
  "ABBR": "MSV-AA-R90",
  "Name": "aerophobous",
  "CrDat": "2042/11/05",
  "Type": "Зенитный ракетный комплекс",
  "Range": "90 км",
  "Ammo": "12 ракет"
}

Пример 2:

Ввод:
ABBR: MSV-LADS
CrDat: 2045/13/40
Type: Лазерное ПВО
Power: 150 kW
^Z

Вывод:
WARING: INCORRECT DATE INPUT
> unnamed.json

Содержимое unnamed.json:
{
  "ABBR": "MSV-LADS",
  "Name": "N/A",
  "CrDat": "N/A",
  "Type": "Лазерное ПВО",
  "Power": "150 kW"
}
