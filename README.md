# **Welcome to CodeQuest!**

### *What's that?*

 - That's a plot-based web-game where you must write python code to go to the next levels

### *How to start this?*

 - Just launch `run.py` file

## **PLOT (open part...)**

You are a stranger. You travel all round the world. But your next destination is the Python country. When you go odd the plane, you think that everything is okay, but...
There's all be sad and angry. You find a airport manager and ask: "What's the hell going here?" And he answers: "Our president was stolen two days ago.." You really wonna try
to help them. You step into THIS. Everybody wishes you good luck with sad faces.. Good luck, my stranger, and find the president until he is not dead!
